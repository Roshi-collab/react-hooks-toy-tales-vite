
# Toy Tales

Toy Tales is a React application for managing a collection of toys.

## Features

- Display all toys from the backend.
- Add new toys through a form.
- Increase the number of likes.
- Donate and delete toys.

## Technologies

- React
- JavaScript
- CSS
- JSON Server
- Vite
- Vitest

## Installation

npm install

## Running the Application

Start the backend:

npm run server

Start the frontend:

npm run dev

## Testing

npm run test
